THREE WEBPAGES - COMBINED PROJECT
================================

FILES
-----
1. combined_3_webpages.html
   One HTML file containing all three websites. Open it in Chrome, Edge, or Firefox.
   Use the buttons at the top to switch between Personal Portfolio, Sweet Treats Bakery,
   and Foodie's Cafe. Each original page is embedded inside this single file, so no
   separate CSS or JavaScript files are needed.

2. webpages_output_screenshots.pdf
   A 3-page PDF containing a full-page browser screenshot of each webpage, in this order:
   Page 1 - Personal Portfolio
   Page 2 - Sweet Treats Bakery
   Page 3 - Foodie's Cafe

3. webpage_1_screenshot.png, webpage_2_screenshot.png, webpage_3_screenshot.png
   Individual screenshot images used to create the PDF.

ORIGINAL FILES
--------------
The three supplied HTML files are also included unchanged as separate files for reference:
- project 1.html
- project 2.html
- project 3.html

HOW TO RUN
----------
1. Extract the ZIP file.
2. Double-click combined_3_webpages.html.
3. Click a website button to preview that website.

NOTES
-----
The combined file uses embedded page source and works offline. The screenshots were
rendered in Chromium at a desktop viewport. The portfolio page had a stray backtick
after its Resume comment; that typo was removed in the combined preview only.
The original files are included for reference.
